## Problem
Thermal images can help make variations across a solar-panel array visible for inspection.

## What I built
The project record contains a thermal hotspot detection interface and a solar-panel robot concept visual.

## How it works
The software interface displays a thermal panel image alongside detection controls. The robot image is presented separately as a concept render.

## Result
The current gallery documents the software interface and the hardware concept. It does not establish physical robot performance.

## What I would improve
A fuller case study will show the detection workflow, representative outputs and any hardware testing that has been completed.
