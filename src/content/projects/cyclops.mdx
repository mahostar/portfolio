## Problem
Long research tasks need organized retrieval and document processing so that a final report can be traced back to its sources.

## What I built
I developed Cyclops as a research-agent pipeline, combining retrieval-augmented generation, staged processing, scraping, PDF handling, and report generation.

## How it works
The workflow moves from queries through source collection and document processing to synthesis. JSON state and deduplication help organize long-running stages.

## Result
Cyclops connects source collection, document processing, and report generation in extended research runs. The implementation is private; its staged workflow is the focus of this case study.

## What I would improve
The next iteration should make citation checks and evaluation of unsupported statements explicit, while improving local-model and OCR processing.
