## Problem
A single image can miss clues that distinguish a live face from a presentation attack. This project explores complementary spatial and temporal features.

## What I built
I developed a multi-modal temporal-aware Vision Transformer project with data collection, training, and inference tools. The implementation targets constrained hardware such as Raspberry Pi 4.

## How it works
RGB images, estimated pseudo-depth, and temporal features feed a lightweight transformer. The workflow includes camera-based data collection and TensorFlow Lite conversion for edge inference.

## Result
The project combines its data-collection, training, and inference tools in one workflow. The repository reports approximately 12 FPS on Raspberry Pi 4; the measurement applies to that project configuration.

## What I would improve
The next comparison should use documented cross-dataset splits and report per-device latency, memory use, and failure cases.
